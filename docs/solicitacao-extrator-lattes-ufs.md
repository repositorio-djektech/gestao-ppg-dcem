# Solicitação de credenciamento institucional junto ao CNPq para uso do Extrator Lattes (API de Currículos) — PPG-DCEM/UFS

**Assunto: Solicitação de credenciamento institucional junto ao CNPq para uso do Extrator Lattes (API de Currículos) — Projeto de Gestão do PPG em Engenharia e Ciência de Materiais**

À autoridade responsável pelo acesso institucional às bases do CNPq (UFS),

O Programa de Pós-Graduação em Engenharia e Ciência de Materiais está implantando um sistema próprio de gestão e avaliação (quadriênio 2025–2028) que consolida dados de produção, orientações, projetos e eventos dos docentes a partir dos currículos Lattes. Hoje, a coleta depende de cada docente baixar manualmente o próprio currículo em XML. Para automatizar essa etapa, solicitamos que a UFS, como entidade educacional, solicite ao CNPq o credenciamento para uso do **Extrator Lattes** (serviço oficial de extração de dados do Currículo Lattes), uma vez que as chaves de API são concedidas exclusivamente a instituições, nunca a indivíduos ou programas isolados.

**Especificações técnicas do que se solicita ao CNPq:**

1. **Chave de API institucional do Extrator Lattes** — credenciamento da UFS junto ao CNPq para acesso ao serviço de extração de dados do Currículo Lattes (documentado em https://cit.cnpq.br, seção Extrator Lattes / Busca por Identificadores), que permite consultar currículos por número de identificação (CPF/ID Lattes) de forma programática;

2. **Finalidade** — integração com o sistema de gestão do PPG-DCEM para: localização dos identificadores Lattes dos docentes vinculados ao programa; extração periódica dos dados curriculares (produção bibliográfica, orientações, projetos, eventos, patentes, mobilidade) no recorte do quadriênio 2025–2028; eliminação do download manual de XML por cada docente;

3. **Volume estimado de uso** — cerca de 16 currículos de docentes do programa, com consultas periódicas (mensais ou por ciclo de atualização do sistema), dentro dos limites estabelecidos pelo CNPq para uso institucional, sem revenda ou redistribuição dos dados;

4. **Responsável institucional** — designar, por parte da UFS, o responsável técnico pela chave (a ser indicado pelo setor competente), com a coordenação do PPG-DCEM como unidade usuária;

5. **Uso e responsabilidade** — a chave será utilizada exclusivamente no sistema de gestão do programa, armazenada de forma segura (cofre de segredos do backend, sem exposição no front-end), em conformidade com os termos de uso do CNPq e com a LGPD, sob responsabilidade da coordenação do PPG-DCEM.

Agradecemos desde já o encaminhamento ao CNPq e permanecemos à disposição para fornecer informações complementares.
